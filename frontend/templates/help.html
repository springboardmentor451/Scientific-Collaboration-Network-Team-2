Getting Started

Researcher Flow

As a Researcher, your primary workflow involves submitting publications, linking your ORCID ID, joining research projects, and checking your co-authorship maps:

  • Submit a publication under the Publications tab. Set status as draft if you are still working on it.
  • Go to Network Graph to visually check which researchers you are connected to.
  • Click Edit Profile inside your user panel to add your research interests and technical skills.

Institution Admin

Institution admins can review department structures, track total publications and grants funding totals across departments, and register institutional partnerships.

Role-Based Access (RBAC)

Permissions Matrix

The platform implements a strict security policy using JWT access tokens. Key permission details:

  • Researcher: CRUD own profile, publications, and conference participations. Can view others.
  • Reviewer: Can view all publication logs (including drafts) and conference events.
  • Institution Admin: CRUD departments and projects for their institution. View all statistics.
  • System Admin: Full CRUD access across users, institutions, audit logs, and reports.

Security Compliance

All mutating endpoints (create, update, delete) automatically trigger a secure entry write inside the global audit logger database table.
